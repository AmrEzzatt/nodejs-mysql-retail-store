🛒 Retail Store Database (Node.js & MySQL)

This project implements a retail store database system using MySQL, designed to manage products, suppliers, and sales.

📌 Overview

The system includes:

Products management
Suppliers management
Sales tracking
SQL operations (DDL + DML + Queries + Permissions)
🛠️ Tech Stack
Node.js
MySQL
SQL (DDL & DML)
📊 Database Design
🧾 Products Table
ProductID (PK, Auto Increment)
ProductName
Price
StockQuantity
SupplierID (FK)
🏢 Suppliers Table
SupplierID (PK, Auto Increment)
SupplierName
ContactNumber
💰 Sales Table
SaleID (PK, Auto Increment)
ProductID (FK)
QuantitySold
SaleDate
